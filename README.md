# VYRA ADS

Site institucional (uma página) da VYRA ADS — gestão de tráfego pago, criação de anúncios e estratégia digital.

Site estático puro (HTML/CSS/JS, sem build). `index.html` é o ponto de entrada; imagens ficam em `assets/img/`.

## Deploy

Publicado no Netlify: https://vyra-saude.netlify.app

`netlify.toml` define a pasta de publicação (`.`) e headers de cache/segurança.

## Desenvolvimento local

Basta abrir `index.html` num servidor estático qualquer (ex.: extensão Live Server, `npx serve`, etc.) — não há passo de build.
